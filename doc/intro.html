Overview

GXemul is a fast full-system computer architecture emulator for vintage RISC workstations and servers. It accurately models complete machines closely enough to run unmodified guest operating systems—such as Ultrix, OpenVMS, NetBSD, OpenBSD, Sprite, and Linux—as if they were running on real hardware.

Rather than merely running bare ELF binaries, GXemul models the entire machine environment:

  • Genuine Console Firmware: Boots from real system ROM dumps (e.g. DEC KN02 and KN03 PROMs, genuine DEC 3000 SRM console firmware V3.3 with real EV4 PALcode) as well as TURBOchannel option ROMs. Built-in PROM emulation is also provided for quick kernel tests without ROM dumps.
  • 2D Accelerated Framebuffers: Color framebuffers including the TURBOchannel PMAG-BA (CX) and smart framebuffer PMAGB-BA (HX / SFB, 1280×1024 with hardware stippling, line drawing, and plane masking), driving graphical environments like DECwindows Motif and X11.
  • Complete I/O Subsystems: NCR 53C94 (ASC) SCSI controllers with IOASIC DMA, AMD LANCE Ethernet, Zilog Z8530 serial controllers, DEC LK201 keyboards, VS423 mice, MC146818 real-time clocks with NVRAM, and SIMH tape image emulation.
  • Flexible Networking: Built-in gateway simulation (transparent outbound TCP/UDP with IP fragment reassembly), L2TPv3 Ethernet tunnels, and host TAP devices.
  • Modern User Controls: Visual machine manager GUI, JSON configuration files, direct-to-MP4 video recording (--record), VNC display support, and an MCP server / control socket for automation.

Installation & Building

Installing Prebuilt Packages

Precompiled packages are available for modern platforms:

  • Debian & Ubuntu: Install from the apt repository: 
    sudo curl -fsSLo /usr/share/keyrings/rpajarola.gpg https://rpajarola.github.io/apt/rpajarola.gpg
echo "deb [signed-by=/usr/share/keyrings/rpajarola.gpg] https://rpajarola.github.io/apt stable main" | sudo tee /etc/apt/sources.list.d/rpajarola.list
sudo apt update
sudo apt install gxemul-rp
  • macOS: Install via Homebrew: 
    brew install rpajarola/tap/gxemul-rp
  • Windows: Download the standalone 64-bit Windows zip from the GitHub Releases page. Unzip and run gxemul.exe in Windows Terminal.

Compiling from Source

GXemul builds on any modern Unix-like operating system (FreeBSD, Linux, macOS, NetBSD, OpenBSD) with a C99 compiler:

$ ./configure
$ make
$ sudo make install

Dependencies: The only optional dependency is SDL2 (e.g. libsdl2-dev on Debian/Ubuntu, or Homebrew's sdl2 on macOS), which enables graphical framebuffer windows and the visual Machines Window. If SDL2 is not installed, GXemul builds in console/terminal mode.

How to Run the Emulator

1. The Visual Machines Window

When started without arguments on a system with SDL2 support, GXemul opens an interactive window:

$ gxemul

From here you can view recently used machines, create new machines, inspect hardware configurations, and launch emulation with a click. See The Machines Window.

2. Using Machine Configuration Files (Recommended)

A machine is best defined by a machine.json configuration file describing its CPU, memory, ROMs, disks, and network interfaces. To launch a configured machine:

$ gxemul machine.json
or:
$ gxemul --config machine.json

To edit a configuration file graphically in the Machines Window:

$ gxemul --edit machine.json

See Configuration Files for format details and ready-to-use examples.

3. Recording Video to MP4

You can record the graphical framebuffer window directly into an MP4 video (requires ffmpeg installed on the host):

$ gxemul --record session.mp4 machine.json

To skip initial firmware probing and start recording only when the screen displays something other than black:

$ gxemul --record-nonblack session.mp4 machine.json

4. Terminal & Serial Console Controls

  • Breaking into the Debugger: In the main controlling terminal, pressing CTRL-C halts emulation and drops into the interactive single-step debugger prompt (GXemul>). Type quit to exit the emulator, or continue to resume.
  • Sending CTRL-C to the Guest: Because CTRL-C is reserved for the debugger, press CTRL-B in the main terminal to send an actual CTRL-C interrupt signal to the guest operating system.
  • Dedicated Telnet Ports (-x): With the -x option, each emulated serial port gets its own TCP port on localhost (from 4000 and up): 
    $ telnet localhost 4000
    In telnet sessions, both CTRL-C and CTRL-B retain their original guest meanings.
  • VNC Display: To view the framebuffer remotely or run headless without an SDL window: 
    $ gxemul --vnc tcp:5900 machine.json

Tested Machines & Operating Systems

The documentation focuses on hardware platforms that have been verified to install and run complete, unmodified operating systems.

DECstation (MIPS)

Digital's MIPS-based workstations with TURBOchannel expansion buses, IOASIC DMA, and SCSI storage.

  • DECstation 5000/200 (3MAX):
    • NetBSD NetBSD/pmax (10.1, 9.3, 8.1, 1.6.2) — full CD install, multi-user, networking, X11.
    • Ultrix Ultrix/RISC 4.5 — full installation with UWS DECwindows on PMAG-BA and HX (PMAGB-BA) 1280×1024 framebuffers.
    • Linux Debian GNU/Linux 3.1 (Sarge) — Linux 2.4 kernel, multi-user.
    • OpenBSD OpenBSD/pmax (2.8 to 5.4) — installs from CD-ROM, multi-user, X11.
    • Sprite Sprite Network OS — boots with genuine ROMs, Ethernet networking.
  • DECstation 5000/133 & 5000/1xx (3MIN):
    • Linux Debian GNU/Linux 3.1 — Linux 2.4 kernel on the 5000/133 with real KN03 PROM and IOASIC timer.
    • NetBSD NetBSD/pmax 10.1 installer — tested with real KN03 PROM.
    • Firmware & HX Real KN02-BA / KN03 PROMs — runs firmware diagnostics, boots disks, and drives the HX (PMAGB-BA) 1280×1024 framebuffer.

→ Read the complete DECstation Installation Guide.

DEC 3000 AXP (Alpha)

Digital's first generation 64-bit Alpha AXP workstations based on the DECchip 21064 (EV4) microprocessor and TURBOchannel bus.

  • DEC 3000 Model 400 (Sandpiper / Pelican):
    • OpenVMS OpenVMS AXP 1.0 — installs from CD-ROM with stand-alone BACKUP, boots to multi-user DCL prompt.
    • DECwindows DECwindows Motif 1.2 — running on the PMAGB-BA (SFB) 1280×1024 accelerated framebuffer with DECterm and Motif Window Manager.
    • DEC OSF/1 DEC OSF/1 AXP V1.2 — installs from CD-ROM, boots multi-user with networking and X/DECwindows.
    • Firmware Genuine SRM Console V3.3 & EV4 PALcode — executes authentic Alpha firmware dumps, runs power-up diagnostics, and handles system calls.

→ Read the complete DEC 3000 AXP Installation Guide.

Other Verified Workstations & Boards

The following hardware platforms are also tested and functional:

  • Motorola 88K:
    • Omron LUNA-88K — runs OpenBSD/luna88k installed onto a SCSI disk image.
    • Motorola MVME187 — runs OpenBSD/mvme88k.
  • MIPS:
    • SGI O2 (IP32) — runs NetBSD/sgimips, OpenBSD/sgi, and real PROM.
    • MIPS Malta & Algorithmics P5064 — runs NetBSD and Linux.
    • Cobalt Microserver (Qube/RaQ) — runs NetBSD/cobalt.
  • ARM:
    • Chalice CATS & Rebel NetWinder — runs NetBSD and OpenBSD.
  • SuperH:
    • I-O DATA Landisk (USL-5P) — runs NetBSD/landisk and OpenBSD/landisk.
    • Sega Dreamcast — runs NetBSD/dreamcast and Linux.
  • PowerPC:
    • IBM 6050/6070 PReP & Artesyn PM/PPC — runs NetBSD.

Note: The source tree also includes synthetic test targets (such as testmips and testalpha, used by regression test suites and compiler builders) and preliminary hardware skeletons. The documentation focuses on the complete, verified systems listed above.
