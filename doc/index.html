GXemul Documentation

Full-system computer architecture emulator for vintage RISC workstations and servers.
Introduction & User Guide DECstation Guide DEC 3000 Alpha Guide Configuration Files Networking GitHub Repository

GXemul models complete, authentic computer systems closely enough to run unmodified guest operating systems as if they were running on real physical hardware. It executes authentic PROM firmware, drives accelerated 2D graphics framebuffers, supports SCSI storage, and handles full networking.

Tested Machines & Operating System Guides

Detailed step-by-step installation guides and machine configurations for tested hardware platforms:

DECstation 5000/200 & 5000/133

Architecture: 32-bit / 64-bit MIPS (R3000 / R4400), TURBOchannel bus, IOASIC DMA, NCR 53C94 SCSI, AMD LANCE Ethernet.

  • NetBSD NetBSD/pmax 10.1 & 9.x (5000/200 and 5000/133)
  • Ultrix Ultrix/RISC 4.5 with UWS DECwindows Motif
  • Linux Debian GNU/Linux 3.1 on 5000/200 & 5000/133
  • OpenBSD OpenBSD/pmax 2.8 & 5.4
  • Sprite Sprite Network OS
  • Firmware Real KN02/KN03 PROMs & Option ROMs
  • Graphics HX (PMAGB-BA) 1280×1024 Framebuffer

DEC 3000 Model 400 (Alpha AXP)

Architecture: 64-bit DECchip 21064 (EV4), TURBOchannel bus, IOCTL with DMA, dual 53C94 SCSI ASIC with TCDS DMA, LANCE Ethernet.

  • OpenVMS OpenVMS AXP 1.0 (stand-alone BACKUP, boots to DCL)
  • DECwindows DECwindows Motif 1.2 Desktop on SFB framebuffer
  • DEC OSF/1 DEC OSF/1 AXP V1.2 (multi-user, networking, X11)
  • Firmware Genuine SRM Console V3.3 & EV4 PALcode
  • Graphics PMAGB-BA (SFB) 1280×1024 accelerated display

Using GXemul

Core user guides covering emulator operation, machine management, networking, and media:

  • Introduction & User Guide: Installation options (apt repository, Homebrew tap, Windows standalone zip, source builds), running the emulator, video recording to MP4 (--record), terminal vs telnet serial consoles (-x), and debugger keys.
  • Configuration Files & Machines Window: How to define systems using machine.json, using the graphical Machines Window (gxemul), machine export/cloning, ROM search paths, and hardware options.
  • Networking: Simulated gateway NAT (transparent outbound TCP/UDP with IP fragment reassembly), L2TPv3 Ethernet tunnels between emulators and host networks, and host TAP devices.
  • Storage, Media & Display Management: Configuring hard disks, using copy-on-write disk overlays (throwaway writes), live CD-ROM and SIMH tape swapping, and remote display with VNC (--vnc).
  • The Control Socket & AI MCP Server: Scripting and inspecting running machines via the Unix domain or TCP control socket (--control and --ctl), and integrating with AI coding assistants via the Model Context Protocol (--mcp).

Debugging & Development Tools

  • Debugging Code Using GXemul: Interactive single-step debugger, setting breakpoints, stepping through instructions, unassembling machine code, dumping CPU registers, inspecting memory, and function call tracing.
  • Bare-Metal Experiments: Writing standalone "Hello World" programs from scratch and experimenting with test CPU models.
