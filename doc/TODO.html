GXemul: Planned Features & Roadmap

This document outlines the roadmap, active development goals, and planned enhancements for GXemul. The primary focus is accurate, high-performance emulation of DECstation (MIPS) and DEC 3000 AXP (Alpha) systems booting real firmware and running production guest operating systems (DEC OSF/1, OpenVMS, Ultrix, NetBSD, OpenBSD, Sprite, Linux, and Windows NT).

For recently implemented features and historical changes, consult the Changelog (HISTORY).

1. DEC 3000 AXP (Alpha EV4)

  • Mouse Input in Graphical Environments: Complete pointer event handling through the SCC / LK201 path under X11 on DEC OSF/1 and DECwindows Motif on OpenVMS.
  • TURBOchannel Option ROM Self-Tests: Ensure the HX (PMAG-RO / SFB) option ROM passes power-up diagnostics cleanly without requiring test skips (TC0 ?? 300).
  • Serial ROM (SROM) Hand-Off: Verify and match the exact real-hardware SROM version encoding passed to console firmware on DEC 3000 Model 400/500/600/700.
  • Console Frequency Calibration: Address the firmware power-up warning WRONG FREQUENCY, CHECK OSCILLATOR where SRM measures the CPU clock against RTC loops.
  • Real Hardware Verification: Verify ambiguous 21064 CPU behaviors against physical machines: AMASK behavior, EXC_SUM register write mask bit ordering (F31–F0 vs I31–I0), and system ROM variants.
  • Diagnostic Memory Test (LL/SC): Investigate the remaining diagnostic failure test LLSC addr = 00200000 in console power-up memory tests.
  • PALmode Translation Optimization: Optimize translation table invalidation on PALmode and privileged mode transitions to boost guest operating system performance.
  • Additional DEC 3000 Peripherals: Implement FEPROM flash programming support, ISDN DMA, and proper LANCE reset / DMA enable control bits in the system status register (SSR).

2. DECstation (MIPS) & Framebuffers

  • TURBOchannel Framebuffer Emulation: Add support for additional TURBOchannel graphics options (such as PMAG-JA, PMAG-RO / SFB on DECstations) and 2D acceleration features where utilized by guest drivers.
  • Multi-Head Display Ergonomics: Improve window management and unified mouse/keyboard focus when running multi-screen configurations (e.g. triple-headed Ultrix setups).
  • FPU Exception Conformance: Validate IEEE floating-point exception handling and status flags against physical R3000/R3010 and R4400 hardware.
  • Timer Pacing & Count Register Precision: Fine-tune MIPS Count and Compare register updates under dynamic translation to prevent guest OS wall-clock drift.
  • DECstation Audio: Emulate the IOASIC ISDN / AMD79C30 audio codec to provide sound output in Ultrix and NetBSD.
  • Sprite Multi-Node Networking: Investigate cross-node root filesystem mounting (/) when executing multiple networked Sprite DECstation instances.

3. Core Dynamic Translation & Emulation Engine

  • Fine-Grained SMP Translation Invalidation: Replace coarse machine-wide translation cache resets with targeted per-page invalidation across CPUs when write-protected code pages are modified.
  • Elimination of Non-Graceful Exits: Continue converting remaining legacy exit(1) aborts into cpu->running = false transitions with proper dyntrans loop termination, returning control to the interactive debugger or console.
  • Hot-Loop Instruction Combinations: Profile instruction combinations on modern 64-bit host processors for tight inner loops (such as memcpy, memset, and kernel idle loops) to generate streamlined native equivalents.
  • Type Safety Cleanup: Modernize remaining legacy integer flags to standard <stdbool.h> bool types across CPU and device contexts.

4. Debugger, MCP & Diagnostics

  • Subsystem Breakpoints: Add commands to trigger breakpoints based on subsystem log output (e.g. breakpoint subsystem disk warn) with clean breakout from the dyntrans loop.
  • Hit Counts and Conditional Triggers: Support breakpoint skip counts (breaking only after $N$ occurrences) and non-stopping execution hit counters displayed via CTRL-T.
  • CLI Debugger Ergonomics: Provide tab completion for guest symbols, support whitespace in address arithmetic expressions (e.g. u pc + 0x40), and add a find command to search memory ranges for byte patterns and strings.
  • Model Context Protocol (MCP) Extensions: Expand the built-in MCP server to provide richer introspection, memory modification, and automation interfaces for AI agents and test harnesses.

5. Networking & Peripheral I/O

  • SLIRP / NAT Throughput Optimization: Improve throughput in user-mode simulated NAT networking by optimizing packet buffering, unacked TCP window handling, and LANCE DMA ring processing.
  • Host Audio Backend: Integrate an SDL2 audio output backend to drive host speakers when emulating sound hardware (DECstation AMD79C30, Alpha ISDN).
  • Web-Based Remote Console & Display Streaming: Expand beyond the existing VNC server (--vnc) and control socket (--control) to provide an optional browser-based console interface for remote and multi-machine virtualization setups.

6. Automated Testing & Verification

  • Automated Guest OS Regression Suite: Implement continuous integration scripts that boot headless guest OS installations (NetBSD, Ultrix, OSF/1, OpenVMS) and verify console milestones, network ping, and disk integrity.
  • Processor Conformance Tests: Expand the standalone test suite in test/ to test additional edge cases in integer arithmetic, MMU translation faults, and floating-point rounding.
